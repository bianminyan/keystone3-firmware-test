# SLIP39 创建成功结果误判修复

关联 Jira：[PRAD-8896](https://keystonejira.atlassian.net/browse/PRAD-8896)

## 背景与范围

PR #98 的 SLIP39 创建校验把成功返回的分片长度误当成错误，正常创建在写入账户前异常退出。本次统一分片校验接口为成功返回零、失败返回错误码；底层解码仍返回长度，不改变导入、forget 或账户恢复的业务规则。

## 需求与场景

### Requirement: 正常校验允许继续创建

系统必须正确识别校验成功结果，不能因返回数据长度而中止创建。

#### Scenario: 创建 20 词钱包

- GIVEN 创建数据有效且分片恢复结果与缓存一致
- WHEN 底层解码得到有效的 16 字节分片，校验接口返回成功
- THEN 继续正常账户创建，不触发异常退出

#### Scenario: 创建 33 词钱包

- GIVEN 创建数据有效且分片恢复结果与缓存一致
- WHEN 底层解码得到有效的 32 字节分片，校验接口返回成功
- THEN 继续正常账户创建，不触发异常退出

### Requirement: 无效数据不能继续创建

系统必须保留创建校验失败时的保护，不得将错误或不一致数据当作成功。

#### Scenario: 校验失败或长度不匹配

- WHEN 校验返回错误，包括底层解码长度与词数不一致
- THEN 中止创建，不调用账户写入流程

#### Scenario: 阈值或恢复数据无效

- WHEN 阈值无效、所需分片缺失、恢复失败或恢复数据与缓存不一致
- THEN 中止创建，不调用账户写入流程
