# 修改密码中断后指纹签名开关状态修复

关联 Jira：[PRAD-8917](https://keystonejira.atlassian.net/browse/PRAD-8917)

## 背景与范围

修改钱包密码时，账户密码可能已经成功写入，但设备在关闭指纹签名开关前重启。重启后开关仍显示开启，而指纹签名保存的旧密码已不能用于该钱包。本次仅修复修改密码与指纹签名开关之间的状态一致性；不改变指纹解锁、指纹录入或其他钱包的设置。

## 需求与场景

### Requirement: 修改密码后关闭目标钱包的指纹签名

系统必须在目标钱包的密码变更生效前持久化关闭其指纹签名开关，不能出现新密码已生效而旧指纹签名开关仍开启的状态。

#### Scenario: 正常修改密码

- GIVEN 目标钱包已开启指纹签名，旧密码正确且新密码可用
- WHEN 用户修改该钱包的密码
- THEN 密码修改成功，目标钱包的指纹签名开关关闭
- AND 其他钱包的指纹设置不受影响

#### Scenario: 密码写入后设备中断

- GIVEN 目标钱包已开启指纹签名且开始修改密码
- WHEN 密码变更过程中设备意外重启
- THEN 重启后不能出现已变更密码的钱包仍显示可用旧指纹签名的状态

### Requirement: 可重试的输入错误不改变指纹设置

系统必须在确认旧密码和新密码满足修改条件后，才改变目标钱包的指纹签名设置。

#### Scenario: 密码校验失败

- GIVEN 目标钱包已开启指纹签名
- WHEN 旧密码错误或新密码与其他钱包密码重复
- THEN 修改密码失败，原有指纹签名开关保持不变
